# SQL Bootcamp

A hands-on SQL learning repository documenting my journey from fundamentals to advanced querying. This repo serves as both a structured study log and a practical reference, combining clear explanations with executable examples.

The focus is on **learning by doing**: writing real SQL, understanding *why* queries work, and building intuition that carries over to real-world databases.

---

## Purpose

* Build a strong foundation in SQL concepts
* Practice writing clean, readable, and efficient queries
* Create a long-term reference for common patterns and techniques
* Track progress and reinforce learning through repetition

---

## Topics Covered

* Database fundamentals
* SELECT statements and filtering
* Sorting and limiting results
* Aggregate functions
* GROUP BY and HAVING
* Joins (INNER, LEFT, RIGHT, FULL)
* Subqueries and nested queries
* String, numeric, and date functions
* Constraints and data integrity
* Basic performance considerations

*(Topics expand as progress continues.)*

## How to Use This Repo

1. Clone the repository
2. Open `.sql` files in your preferred SQL client or editor
3. Run queries against a local or sandbox database
4. Read comments and notes alongside the queries
5. Modify and experiment — breaking things is encouraged

---

## Learning Philosophy

This repository prioritizes:

* **Clarity over cleverness**
* **Understanding over memorization**
* **Consistency over speed**

Each section builds on the last, reinforcing core ideas while introducing new patterns.
