# Overview of Databases

## What are Databases?
## Why use Databases?

### Definition
- Databases are systems that allow users to store and organize data.
- They are useful dealing with large amounts of data.

### Typical Users
- Databases have a wide variety of users!
- Analysts
  - Marketing
  - Business
  - Sales
- Technical
  - Data Scientist
  - Software Engineers
  - Web Developers
- Basically anyone needing to deal with data!

### From Spreadsheets to Databases
- Most users have some familiarity with spreadsheet software (such as Excel)
- Spreadsheets
  - One-time analysis
  - Quickly need to chart something out
  - Reasonable data set size
  - Ability for untrained people to work with data
- Databases
  - Data Integrity
  - Can handle massive amounts of data
  - Quickly combine different datasets
  - Automate steps for re-use
  - Can support data for websites and applications
